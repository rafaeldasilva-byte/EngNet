# 🚀 Desafio 3 - Frontend | EngNet

Projeto desenvolvido como parte do **Desafio 3** do programa de trainee da **EngNet**, com foco na fidelidade visual e estruturação web a partir de um protótipo construído no Figma.

🔗 **[Acessar o Projeto (GitHub Pages)](https://www.google.com/search?q=https://rafaeldasilva-byte.github.io/EngNet/)**

🎨 **[Visualizar Protótipo no Figma](https://www.figma.com/design/erp9NeXDHFwpsZ9nYBWNgX/Desafio3-Frontend?node-id=0-1&t=plgikNlCtrHXvoXK-0)**

---

## 📌 Sobre o Projeto

O objetivo do desafio é implementar a interface web seguindo as especificações de layout, tipografia, cores e elementos visuais do Figma, garantindo boas práticas de desenvolvimento frontend, estruturação HTML semântica e interatividade via JavaScript.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estrutura e marcação semântica do projeto.
* **CSS3**: Estilização e integração de fontes personalizadas.
* **JavaScript (ES6+)**: Manipulação de elementos e lógica dinâmica (`app.js`).
* **Git & GitHub Pages**: Versionamento do código e publicação da aplicação.

---

## 📁 Estrutura do Repositório

```text
Desafio3-Frontend/

├── img/            # Imagens, ícones e assets visuais

```

---

## 💻 Como rodar o projeto localmente

1. Clone o repositório:
```bash
git clone https://github.com/rafaeldasilva-byte/EngNet.git

```


2. Acesse a pasta do projeto:
```bash
cd EngNet

```


3. Mude para a branch do desafio:
```bash
git checkout rafaeldasilva-byte-Desafio3

```


4. Abre o arquivo `index.html` diretamente no seu navegador ou execute através do *Live Server* no seu editor de código (como o VS Code).
